# 🤖 Machine Learning Algorithms Repository

This repository contains implementations of major Machine Learning algorithms including **Supervised Learning, Unsupervised Learning, and Reinforcement Learning**.  
All algorithms are implemented in **Python (Jupyter Notebook / Google Colab style)** with step-by-step explanation for easy understanding.

# 🚀 Features

- Cell-by-cell notebook format
- Visualization of results
- Covers core ML concepts used in academics & interviews

- Linear Regression
- Logistic Regression
- KNN (K-Nearest Neighbors)
